# متجر Key of Life — نسخة GitHub Pages

هذه النسخة تعمل مباشرة على GitHub Pages بدون تثبيت برامج أو تشغيل خادم.

## الملفات

- `index.html`: الصفحة الرئيسية وترتيب أقسام الموقع.
- `styles.css`: الألوان والتصميم واستجابة الموبايل.
- `products.js`: المنتجات والأسعار وبيانات استقبال الطلبات.
- `app.js`: البحث والفلاتر والسلة وإرسال الطلب.
- `.nojekyll`: يجعل GitHub يعرض الملفات كما هي.

## أول تعديل قبل النشر

افتح ملف `products.js`، ثم عدّل الجزء الموجود في أوله:

```js
window.STORE_CONFIG = {
  storeName: "Key of Life",
  currency: "USD",
  orderEmail: "orders@yourdomain.com",
  whatsappNumber: "12025550123"
};
```

- رقم واتساب يُكتب بكود الدولة بدون علامة `+` وبدون مسافات.
- إذا وضعت رقم واتساب، زر الطلب سيرسل السلة إلى واتساب.
- إذا تركت واتساب فارغًا ووضعت الإيميل، سيرسل الطلب بالإيميل.

## إضافة منتج جديد

داخل `products.js` انسخ سطر منتج كامل داخل قائمة `window.PRODUCTS` ثم عدّل:

```js
{
  id: 13,
  name: "Product Name",
  category: "Accessories",
  price: 49,
  oldPrice: 59,
  image: "images/product-13.jpg",
  badge: "New",
  details: "Gold · Silver"
}
```

يجب أن يكون `id` مختلفًا لكل منتج. الأقسام المتاحة:

- `Lingerie`
- `Egyptian Gifts`
- `Accessories`
- `Home Decor`

لإخفاء السعر القديم أو الشارة، احذف `oldPrice` أو `badge` من المنتج.

## استخدام صورك

1. أنشئ مجلدًا باسم `images` بجوار الملفات.
2. ضع صور المنتجات داخله بأسماء إنجليزية بدون مسافات، مثل `red-robe.jpg`.
3. اكتب في المنتج: `image: "images/red-robe.jpg"`.
4. يُفضّل أن تكون الصور رأسية وبمقاس قريب من `900 × 1150` بكسل.

## الرفع على GitHub Pages

1. ادخل إلى GitHub واضغط `New repository`.
2. اكتب اسمًا مثل `key-of-life-store` واختر `Public`.
3. اضغط `Create repository`.
4. اضغط `uploading an existing file`.
5. ارفع محتويات هذا المجلد نفسها، وليس ملف ZIP.
6. اضغط `Commit changes`.
7. افتح `Settings` ثم `Pages`.
8. تحت `Build and deployment` اختر `Deploy from a branch`.
9. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط `Save`.
10. بعد عدة دقائق سيظهر رابط المتجر.

## ملاحظات مهمة

- السلة تُحفظ على جهاز العميل باستخدام المتصفح.
- الموقع يعرض الأسعار ويرسل ملخص الطلب، لكنه لا يخصم أي مبالغ.
- الدفع الإلكتروني، المخزون المركزي، الضرائب التلقائية، وحساب الشحن تحتاج خدمة متجر أو نظام خلفي إضافي.
- الصور الحالية تجريبية ويجب استبدالها بصور منتجاتك قبل الإطلاق الرسمي.
